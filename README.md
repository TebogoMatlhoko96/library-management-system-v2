# Library Management System V2

A simple library management system for a junior software developer portfolio.

## Version 2 Features

### Books
- Add books
- Edit books
- Delete books
- Search by title or author
- Filter by category
- Filter by available, borrowed, or overdue
- Borrow and return books

### Members
- Add members
- Edit members
- Delete members
- Search members
- Prevent deletion of members with active borrowed books

### Borrowing
- Select a registered member when borrowing
- Set a due date
- Automatically detect overdue books
- Track borrowing history
- Record return dates

### Dashboard
- Total books
- Available books
- Borrowed books
- Overdue books

### Storage
Data is stored in browser `localStorage`.

## How to run

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Add members.
4. Add books.
5. Borrow a book using a registered member.
6. Return the book and check the borrowing history.

No installation or backend is required.
